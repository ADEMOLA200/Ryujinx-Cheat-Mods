# Switch Emulator Mod Database

Switch Emulator Mod Database is a collection of cheats, FPS, and graphics mods for various Nintendo Switch games running on the Yuzu/Ryujinx/Sudachi/Citron..etc emulator. This repository brings together multiple modding projects, allowing you to enhance your gaming experience with improved visuals and gameplay tweaks.

## Features

- **Cheats**: Activate in-game cheats to modify gameplay behavior.
- **FPS Mods**: Increase the frame rate for smoother gameplay.
- **Graphics Mods**: Enhance the visual quality of your favorite Switch games.

## How to Use

1. **Download** the mods from this repository.
2. **Install** them following the guidelines provided in each mod's documentation.
3. **Launch** your game with Yuzu/Ryujinx/Sudachi/Citron...etc and enjoy the enhancements!

*Note: Always back up your original game files before applying any mods.*
